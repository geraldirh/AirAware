Real-Time Monitoring

Data sensor diperbarui secara langsung melalui WebSocket ke Node-RED. Lihat perubahan kualitas udara dalam hitungan detik tanpa refresh halaman.

📈

Grafik & Tren Data

Visualisasi data historis mingguan dan tren live lingkungan dengan grafik interaktif. Identifikasi pola kualitas udara sepanjang waktu.

🔔

Notifikasi WhatsApp

Scan QR code untuk langsung mendaftar ke Twilio Sandbox. Peringatan otomatis dikirim saat suhu, kelembaban, atau AQI melebihi ambang batas berbahaya.

🌡️

Multi-Parameter Sensor

Memantau 5 parameter sekaligus: Suhu, Kelembaban, PM2.5 (partikel halus), CO₂/Gas, dan Indeks Kualitas Udara (AQI) secara bersamaan.
