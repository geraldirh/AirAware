Real-Time Monitoring

Data sensor diperbarui secara langsung melalui WebSocket ke Node-RED. Lihat perubahan kualitas udara dalam hitungan detik tanpa refresh halaman.

📈

Grafik & Tren Data

Visualisasi data historis mingguan dan tren live lingkungan dengan grafik interaktif. Identifikasi pola kualitas udara sepanjang waktu.

🔔

Notifikasi WhatsApp

Daftarkan nomor WhatsApp untuk menerima peringatan otomatis saat suhu, kelembaban, atau AQI melampaui ambang batas berbahaya via Fonnte API.

📖 Cara Penggunaan
1
Aktivasi Sandbox Twilio
Kirim pesan WhatsApp berisi join [kode-sandbox] ke nomor WhatsApp Sandbox Twilio Anda untuk mengaktifkan penerimaan pesan.
2
Konfigurasi Kredensial Twilio
Masukkan **Account SID**, **Auth Token**, dan **Sender Number** Anda ke panel kiri, lalu klik **Simpan Kredensial**.
3
Isi Form Penerima
Masukkan **Nama** dan **Nomor WhatsApp** penerima dengan format 628xxxxxxxxxx.
4
Uji Koneksi API
Klik tombol Kirim Test untuk mengirim pesan WhatsApp simulasi langsung dari browser Anda ke nomor tujuan.
5
Aktifkan Pemantauan
Klik tombol Daftarkan Nomor. Browser Anda otomatis mengirim pesan peringatan real-time jika sensor mendeteksi udara memburuk!
