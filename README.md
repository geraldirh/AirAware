AirAware

AirAware is an IoT-based air quality monitoring system that collects, analyzes, and visualizes environmental data in real-time to help users understand and improve their surrounding air conditions.

Tujuan utama AirAware adalah meningkatkan kesadaran terhadap kualitas udara di sekitar pengguna serta menyediakan data yang dapat digunakan untuk pengambilan keputusan terkait kesehatan dan lingkungan.

Fitur Utama
📡 Monitoring kualitas udara secara real-time
🌡️ Pengukuran suhu dan kelembapan lingkungan
☁️ Pengiriman data ke server/cloud
📊 Dashboard visualisasi data
🔔 Notifikasi ketika kualitas udara berada di luar batas aman
📈 Penyimpanan data historis untuk analisis tren
